# মাদ্রাসা ম্যানেজমেন্ট সফটওয়্যার (Madrasa Management Software)

একটি আধুনিক, অফলাইন-ফার্স্ট প্রগ্রেসিভ ওয়েব অ্যাপ্লিকেশন (PWA) যা দুর্বল নেটওয়ার্ক বা ইন্টারনেট ছাড়াও প্রত্যন্ত অঞ্চলের হিফজ শিক্ষক, প্রবীণ মুহতামিম এবং মাদ্রাসার হিসাবরক্ষকদের সহজে পরিচালনা করার জন্য তৈরি।

---

## 🌟 প্রধান সুবিধাসমূহ (Core Features)

1. **৩-ট্যাপ হিফজ ও নাজেরা ট্র্যাকার (Hifz & Nazera Halqa Tracker):**
   - শিক্ষককে টাইপ করতে হবে না; ১–১১৪ সূরার ড্রপডাউন এবং ১–৩০ পারার সূচিপত্র রেডি।
   - ৩-ট্যাপে পড়ার মান নির্বাচন: `[ মুমতাজ 🟢 ]`, `[ জাইয়িদ জিদ্দান 🔵 ]`, `[ জাইয়িদ 🟡 ]`, `[ মাকবুল 🟠 ]`।
   - **📲 এক ক্লিকে হোয়াটসঅ্যাপে পাঠান:** কোনো এসএমএস গেটওয়ে বা অতিরিক্ত খরচ ছাড়াই সরাসরি `wa.me` লিঙ্কের মাধ্যমে প্রফেশনাল বাংলা কার্ড আকারে অভিভাবকের নম্বরে পাঠানো।

2. **শরীয়াহ ফান্ড ও আর্থিক লেজার (Shariah Cashbook & Receipts):**
   - **ফান্ড বিভাজন:** যাকাত/লিল্লাহ ফান্ড, সাধারণ/বেতন ফান্ড এবং উন্নয়ন ফান্ড।
   - **স্মার্ট শরীয়াহ গার্ডরেল:** যাকাত ও লিল্লাহ ফান্ড দিয়ে উস্তাদদের বেতন বা মাদ্রাসা নির্মাণে খরচ করতে গেলে সাথে সাথে লাল সতর্কতা প্রদর্শিত হয়।
   - **দ্বৈত কপি মানি রিসিট প্রিন্ট:** একই পাতায় `ছাত্র কপি` + `মাদ্রাসা অফিস কপি` সহ ক্রিস্টাল-ক্লিয়ার প্রাতিষ্ঠানিক রসিদ প্রিন্ট এবং ৮০মিমি থার্মাল স্লিপ প্রিন্ট টগল।

3. **বোর্ডিং ও মেস ডাইনিং কাউন্টার (Chef's Meal Screen):**
   - বাবুর্চির জন্য বড় ফন্টের মিনিমাল স্ক্রিন:  
     `মোট আবাসিক ছাত্র − (ছুটিতে থাকা + অসুস্থ) = আজকের সক্রিয় মিল সংখ্যা`।
   - এক ক্লিকে আবাসিক ছাত্রদের খানা বন্ধ, ছুটি বা অসুস্থ মার্ক করা।

4. **শিক্ষার্থী ও ভর্তি ব্যবস্থাপনা (Students & Digital ID Card):**
   - নূরানী, নাজেরা, হিফজ ও কিতাব বিভাগের ছাত্রদের ডিজিটাল প্রোফাইল।
   - তাৎক্ষণিক ডিজিটাল পরিচয়পত্র (Student ID Card) প্রিন্ট।

5. **অফলাইন-ফার্স্ট ও লোকাল ব্যাকআপ (Offline Engine):**
   - ইন্টারনেট চলে গেলেও ব্রাউজারের লোকাল মেমরি (Dexie.js / IndexedDB)-তে সকল ডাটা অক্ষত থাকবে।
   - নেট ফিরলে স্বয়ংক্রিয় ব্যাকগ্রাউন্ড সিঙ্ক।
   - কমিটির ভয় দূর করতে এক ক্লিকে সম্পূর্ণ ডাটাবেজ ব্যাকআপ (JSON) ডাউনলোড ও রিস্টোর।

## 🚀 কীভাবে চালাবেন (How to Run)

১. টার্মিনালে প্রজেক্ট ফোল্ডারে প্রবেশ করুন:
```bash
git clone https://github.com/early-bird313/Madrasha-Management-Software.git
cd Madrasha-Management-Software
npm install
```

২. ডেভলপমেন্ট সার্ভার চালু করুন:
```bash
npm run dev
```

৩. ব্রাউজারে প্রবেশ করুন:
```
http://localhost:3000
```

> **নোট:** সফটওয়্যারটি চালু করলেই স্বয়ংক্রিয়ভাবে বাস্তবসম্মত নমুনা তথ্য (দারুল উলুম মাদ্রাসা, শিক্ষার্থী, হিফজ লগ, ক্যাশবুক ইত্যাদি) সহ ডেমো মোডে চলবে। কোনো ক্লাউড সেটআপ ছাড়াই সাথে সাথে ব্যবহার শুরু করা যাবে!
